## 요구사항

- 두 유저가 Wi-Fi Aware를 이용해 P2P 연결을 한다
- 한 유저는 "작가", 다른 한 유저는 "모델" 역할을 한다
- 작가는 모델을 찍는다. 이때 작가가 보는 카메라 프리뷰가 모델에게 전송된다.
- 둘은 상호작용하면서 모델이 원하는 사진을 찍는다.

### 기술적 어려움
- 어떻게 카메라 프리뷰를 스트리밍할 수 있을까? (1편)
- 수신한 프레임을 어떻게 화면에 그려야할까? (2편)
- 더 효율적으로 스트리밍하려면 어떻게 해야할까? (3편)
